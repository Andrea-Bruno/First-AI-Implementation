To install Cilian with WinBoard 4.0.0
-------------------------------------

1. Open an Explorer.
2. Find the WB-Setup directory, and launch the file "Setup.exe".
3. Now WinBoard is installed. Copy then the folder "Cilian" into the 
   "C:\Progra~1\".

4. Copy the "WinBoard.ini" into the WinBoard's folder ("C:\Progra~1\WinBoard"), 
   or modify your "WinBoard.ini" according to the following:

   /firstChessProgramNames="GNUChess /initString=\"new\\neasy\\n\" \"Cilian 
   -hash17 -xboard -mvnw\" /initString=\"new\\nset 3 6\\n\" "
   /secondChessProgramNames="GNUChess /initString=\"new\\neasy\\n\" \"Cilian 
   -hash17 -xboard -mvnw\" /initString=\"new\\nset 3 6\\n\" "

5. Copy the 3 icons onto your desktop.

Double click on an icon to start Cilian!
